# BlackHole 🚀 极速智能分流客户端

BlackHole 是一款开箱即用的跨平台专线加速与流量智能分流客户端。集成速游专线、火星链原生协议与 ViewTurbo 高速网络，支持 TUN 虚拟网卡接管、智能域名过滤、局域网共享与零服务器 OTA 自动更新。

## ✨ 核心特性

- **三网无缝加速**：集成速游全协议专线、火星链无窗底层核心与 ViewTurbo 专网节点。
- **智能网页域名过滤**：100% 精准嗅探真实访问域名，支持一键切换直连 / 代理 / 拦截。
- **全流量 TUN 虚拟网卡**：支持系统代理与 TUN 虚拟网卡智能联动互锁，防止网络死锁与端口冲突。
- **局域网共享代理**：一键开启热点/局域网代理，内网设备输入本机 IP 端口即可极速连通。
- **零服务器 OTA 自动更新**：基于 GitHub Releases 与国内高速镜像，无感检查、断点续传与自替换。
