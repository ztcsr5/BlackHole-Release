# BlackHole

BlackHole 是一款轻量、现代化的本地网络连接管理与系统效率工具。支持可视化连接监控、智能域名规则管理与多场景连接调度。

## 📦 下载与安装

- **Windows 10 / 11 (64-bit)**:
  👉 [**下载 BlackHole.exe**](https://github.com/ztcsr5/BlackHole-Release/releases/download/v1.0.0/BlackHole.exe)

> 免安装独立执行文件，双击直接运行即可。

## 💡 功能特性

- **连接洞察与状态监控**：实时呈现应用网络活动与连接状态。
- **智能规则与域名管理**：基于访问目标提供灵活的规则过滤与响应决策。
- **局域网共享与调试**：支持便捷的内网连接共享与快速调试。
- **平滑自动更新**：内置版本检查与无感更新体验。
